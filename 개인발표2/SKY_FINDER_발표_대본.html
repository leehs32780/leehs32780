SKY FINDER 핵심 발표 대본

권장 발표 시간: 5분

1. 소개

안녕하세요. SKY FINDER는 출발지와 목적지, 날짜를 입력해 항공편을 비교하고 예약하는 React 웹앱입니다. 회원가입·로그인, 결제 PIN, 예약 조회와 Q&A까지 하나의 흐름으로 구현했습니다.

3. 핵심 코드

App.jsx 26~133번째 줄 — useState

검색 조건, 검색 결과, 사용자와 예약 정보를 상태로 관리합니다. 상태가 바뀌면 React가 화면을 다시 렌더링합니다.

App.jsx 202~205 / appData.js 277~306번째 줄 — useMemo

출발 공항이 변경될 때만 가능한 목적지를 계산하므로 연결되지 않은 노선은 나타나지 않습니다.

App.jsx 230~263 / appData.js 308~344번째 줄 — 검색

필수값을 검사하고 노선별 항공사, 시간, 좌석과 가격이 포함된 발표용 항공편 10개를 생성합니다.

App.jsx 265~289번째 줄 — 왕복 처리

편도는 선택 즉시 예약 창을 열고, 왕복은 가는 편 저장 후 출발·도착지를 반대로 바꾸어 오는 편을 생성합니다.

appData.js 255~275 / PriceChart.jsx 2~73번째 줄

UTC 변환으로 도착지 현지 시각을 계산하고, 외부 라이브러리 없이 SVG 좌표로 가격 그래프를 그립니다.

4. 백엔드 역할을 대신하는 코드

실제 서버와 DB는 없습니다. 아래 기능은 프론트엔드의 localStorage로 백엔드 역할 일부를 구현한 발표용 기능입니다.

기능코드 위치역할
회원가입App.jsx 390~421중복 검사 후 계정 저장
로그인133~152, 363~388계정 비교, 로그인 복원
결제수단·PIN291~302, 503~586카드 관리와 PIN 확인
예약304~361, 680~697예약 저장·조회·취소
Q&A103~131, 193~199, 649~673질문 저장·삭제
회원가입 시 계정을 localStorage에 저장하고 로그인 시 입력값과 비교합니다. 결제 완료 후 항공편, 탑승객과 결제 정보를 예약 객체로 저장합니다. 실제 서비스에서는 백엔드 API, 비밀번호 해시, 인증 토큰, 데이터베이스와 결제사 API가 필요합니다.

5. 시연 순서

  1. 회원가입·로그인
  2. 프로필에서 PIN 설정
  3. 왕복 노선과 날짜 검색
  4. 가는 편·오는 편 선택
  5. 정보 입력 후 결제
  6. 내 예약 확인

6. 마무리

React의 상태 관리, 이벤트 처리와 조건부 렌더링을 검색부터 결제와 예약 조회까지 연결했습니다. 현재 항공편은 발표용 데이터이고 localStorage는 보안 저장소가 아닙니다. 앞으로 실제 API와 백엔드를 연결해 발전시키고 싶습니다. 감사합니다.

예상 질문

왜 React인가요? 상태에 따라 변하는 화면을 컴포넌트로 관리하기 좋기 때문입니다.

실제 항공권인가요? 취항 범위는 참고했지만 시간과 가격은 발표용 데이터입니다.

백엔드가 있나요? 없으며 localStorage로 흐름을 구현했습니다.
