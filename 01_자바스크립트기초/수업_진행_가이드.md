## 2. 이 시간이 어떻게 나온 숫자인지

지어낸 숫자가 아니라 **실제로 센 항목 수 × 항목당 시간**입니다.
학원 속도가 다르면 아래 항목당 시간만 바꿔서 다시 계산하시면 됩니다.

| 항목 | 잡은 시간 | 근거 |
|---|---|---|
| 개념 섹션 1개 | 4분 | 설명 + 실행 + 출력 확인 |
| ✏️ 직접 해보기 1개 | 3분 | 그 자리에서 한두 줄 고쳐 보는 것 |
| 연습문제 (기본) | 5분 | |
| 연습문제 `[응용]` | 8분 | |
| 연습문제 `[도전]` | 12분 | |
| 에러 확인 문항 | 3분 | 주석 풀고 → 확인 → 다시 주석 |
| 13단원 종합 1단계 | 12분 | 사실상 미니 프로젝트 단계 |

> 예를 들어 "개념 섹션 하나에 6분은 걸린다" 싶으면 전체가 73시간 → 87시간이 됩니다.

## 5. 시간이 모자랄 때 — 자르는 순서

위에서부터 자르세요. 아래로 갈수록 자르면 손해가 큽니다.

1. **`[도전]` 문제** — 각 단원 뒤쪽에 있습니다. 빼도 다음 단원에 지장 없습니다. (14문항, 2.8시간)

   > **딱 하나 예외 — 11단원 [도전](문제 15)은 자르지 마세요.**
   > 11단원 연습문제 16개 중 개념05(이벤트 위임)를 다루는 문제는 기본 문제 13과 이것 둘뿐입니다
   > (문제 1~11·13은 개념01~03·05, 문제 12·14는 개념04). 그런데 13단원 종합03 문제 5와
   > 종합04 문제 6이 정면으로 이벤트 위임을 요구하고, 종합03 파일 자신이
   > "이 실습에서 가장 어려운 것은 문제 5(위임 + dataset 문자열 변환)"라고 적어 두었습니다.
   > 이걸 자르면 학생은 위임을 한 번도 손으로 써 보지 않은 채 종합 실습에 들어갑니다.
2. **✏️ 직접 해보기의 절반** — 짝수 번호만 하는 식. (158개, 7.9시간)
3. **개념 파일의 `자주 하는 실수` 섹션을 읽기 과제로** — 65개 개념 파일에 하나씩 있습니다.
   수업에서는 아래 7번 표의 것만 시연. (65개, 4.3시간)
4. **13단원 종합 04(사용자 검색)** — 12단원 내용이 겹칩니다. 종합 03까지만 해도 마무리가 됩니다. (7단계, 1.4시간)

네 가지를 다 자르면 16.4시간이 빠져 **약 57시간**이 됩니다.
여기서 더 줄여야 하면 개념 설명 속도를 올리는 수밖에 없습니다.

**절대 자르지 말 것**
- 각 단원의 **에러 확인 문항**(맨 마지막). 3분짜리인데 학생이 에러 메시지를 읽는 훈련이 여기밖에 없습니다.
- **05단원 `개념03_return`, `개념05_화살표함수`**. 08단원부터 전부 이것 위에 쌓입니다.
- **08단원 `개념06_sort`**. 비교 함수 반환값을 모르면 13단원에서 막힙니다.
- **11단원 `개념05_이벤트_위임`과 그 [도전] 문항(문제 15)**. 종합03·04가 요구합니다.

## 7. 단원별로 반드시 짚어야 할 함정

각 개념 파일 맨 뒤에 `자주 하는 실수` 가 있습니다. 그중 **수업에서 꼭 시연해야 할 것**만 뽑았습니다.

| 단원 | 반드시 시연할 것 |
|---|---|
| 01 | `"10" + 5` 가 `105` 인 것. 형변환을 여기서 못 잡으면 계속 따라옵니다 |
| 02 | `0.1 + 0.2`, 그리고 `toFixed()` 결과가 **문자열**이라는 것 |
| 03 | `=` 와 `===` 혼동, falsy 값 목록 |
| 04 | **무한 루프를 일부러 한 번 내 보기** (Ctrl+C 로 멈추는 법까지) |
| 05 | `return` 뒤에서 줄바꿈하면 값이 안 넘어오는 것 (ASI). 눈으로 안 보이는 에러라 반드시 시연 |
| 05 | 화살표 함수에서 `{ }` 를 쓰고 `return` 을 빼면 **에러 없이 조용히 `undefined`** |
| 06 | `slice`(새 배열) vs `splice`(원본 변경) |
| 07 | 메소드를 변수에 떼어 담으면 `this` 가 풀리는 것 — **에러가 안 나고 값만 틀립니다** |
| 08 | `sort` 비교 함수는 **true/false 가 아니라 음수/양수**를 돌려줘야 한다는 것 |
| 08 | `forEach(console.log())` 처럼 괄호를 붙이면 안 되는 것 |
| 09 | 스프레드는 **얕은 복사** — 안쪽 객체는 같이 딸려 갑니다 |
| 10 | `querySelector` 가 못 찾으면 `null`, 그 다음 줄에서 터진다는 것 |
| 11 | `addEventListener("click", 함수())` 처럼 괄호 붙이는 실수 — **가장 흔합니다** |
| 11 | 이벤트는 '바뀔 때'만 실행되므로 **처음 한 번은 직접 불러야** 한다는 것 |
| 12 | **`fetch` 는 404를 실패로 치지 않습니다.** `res.ok` 를 직접 봐야 합니다 |
| 14 | `import` 는 `./` 와 `.js` 를 반드시 붙인다는 것 (React 에서는 생략되어 헷갈립니다) |
| 14 | localStorage 는 **문자열만** 저장됩니다. 객체는 `JSON.stringify` 없이 넣으면 내용이 통째로 사라집니다 |
| 14 | `getMonth()` 는 0부터. 8월이 7로 나옵니다 |

## 8. 학생이 반드시 물어보는 질문

**자료에 답이 이미 있는 것** — 그 자리를 펴서 읽어 주시면 됩니다.

| 질문 | 답이 있는 곳 |
|---|---|
| "한글로 변수 이름 만들면 안 돼요?" | `01/개념02` 섹션 4 맨 아래 |
| "화살표랑 `function` 중 뭐 써요?" | `08/개념01` 섹션 5 — "메소드는 일반 함수, 콜백은 화살표" |
| "`reduce` 꼭 써야 돼요?" | `08/개념05` 정리 직전 — "억지로 쓰지 마세요"까지 적혀 있습니다 |
| "`input`이요 `change`요?" | `11/개념03` — "글자 입력칸에서는 input 을 훨씬 많이 씁니다" |
| "`then`이요 `await`요?" | `12/개념04` 머리말 — "요즘 실무 코드는 거의 다 이 방식" |
| "`await` 를 왜 두 번 써요?" | `12/개념03` 섹션 1 — 정면으로 답합니다 |

**자료에 답이 없어 강사가 답해야 하는 것** — 미리 준비해 두세요.

| 단원 | 질문 | 이렇게 답하시면 됩니다 |
|---|---|---|
| 02 | "`**`(제곱)는 언제 써요?" | 넓이·복리 계산. `%`(나머지)는 짝수 판별·나누어 담기에 계속 씁니다 |
| 02 | "`Math.round`랑 `toFixed` 중 뭐요?" | **계산에 다시 쓸 값은 `round`(숫자), 화면에만 보여 줄 값은 `toFixed`(문자열)** |
| 04 | "`i++` 말고 `++i`는요?" | 반복문의 증감 자리에서는 그 결과를 아무도 안 써서 둘이 똑같습니다 |
| 04 | "반복문 밖에서 `i` 쓰려면요?" | 밖에 `let last = 0` 을 두고 안에서 넣어 두면 됩니다 |
| 06 | "원본이 바뀌면 뭐가 나쁜데요?" | 장바구니를 정렬해 버리면 **담은 순서로 돌아갈 방법이 없습니다** |
| 06 | "`push`요 `concat`이요?" | 내 배열을 늘릴 땐 `push`, 원본을 두고 새 배열이 필요할 땐 `concat`/스프레드 |
| 07 | "왜 함수를 객체에 넣어요?" | `배열.push()` 처럼 **데이터와 그 데이터를 다루는 동작을 한 덩어리로** 묶는 것 |
| 09 | "`structuredClone` 이 다 해 주면 그거 쓰면 되잖아요?" | 느리고, 함수나 화면 요소가 들어 있으면 실패합니다. 보통은 한 겹 복사로 충분합니다 |
| 10 | "고쳤는데 화면이 그대로예요" | `Ctrl+S` → 브라우저에서 `F5`. 이 두 단계를 매번 해야 합니다 |
| 11 | "인터넷 예제엔 `onclick="hello()"` 던데 거긴 괄호가 있는데요?" | **HTML 속성 안이라 규칙이 다릅니다.** 거기선 괄호가 맞고, 우리는 그 방식을 안 씁니다 |

## 9. 자료 읽는 규칙

| 표기 | 뜻 |
|---|---|
| `// 출력:` | 터미널(node)에 찍히는 값 |
| `// 콘솔:` | 브라우저 F12 Console 에 찍히는 값 |
| `// 화면:` | 브라우저 화면에 보이는 변화 |
| `── 섹션 N ──` | 개념 파일 안의 구분 |
| `✏️ 직접 해보기` | 그 자리에서 해 보는 것. **정답은 파일 맨 아래 주석 블록** |
| `[실수 N]` | 자주 하는 실수. 주석 처리되어 있으니 풀어서 확인 후 다시 주석 |
| `[응용]` / `[도전]` | 연습문제 난이도. 각 단원 뒤쪽 |

**`// 출력:` 에 적힌 값은 전부 실제로 실행해서 맞춘 것입니다.**
학생 출력이 다르면 99%는 오타입니다. 환경 문제는 파일 전체가 안 돌아갈 때만 의심하세요.
(학생용 README 에도 "다르게 나오면 어딘가 잘못 친 것" 이라고 적어 두었습니다)

다만 12단원 ✏️ 는 성격이 조금 다릅니다. 비동기는 결과가 나올 때까지 기다려야 해서
"한 줄 고쳐 보기" 보다 **결과를 먼저 예상하고 확인하기** 형태가 많습니다.
그래서 12단원에서는 **강사가 그 자리에서 값을 바꿔 보여 주는 시간**을 조금 더 잡으시면 됩니다.

10~12단원은 저장 후 **새로고침(F5)** 을 해야 반영됩니다. 학생들이 가장 많이 놓치는 부분입니다.
